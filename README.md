# المنصة السورية لإدارة وجدولة الري — v0.8

منصة ويب تعمل كلياً في المتصفح لحساب ET₀ وفق FAO-56 Penman–Monteith والموازنة المائية في منطقة الجذور وتنبيهات الري في سورية.
النسخة الحالية HTML/JavaScript، والانتقال إلى ASP.NET Core/Blazor مؤجَّل إلى المرحلة الأخيرة.

## ما الجديد في v0.8
1. **التوقعات الجوية:** يُنزَّل Open-Meteo مرتين يومياً على GitHub (07:17 و16:23 بتوقيت دمشق)، على خلايا شبكة ناسا نفسها، ويتضمن:
   - 14 يوماً من تحليل النموذج تسدّ تأخر ناسا.
   - 8 أيام توقع.
   - ET₀ محسوبة بمحرك المنصة (FAO-56، مسار RHmin/RHmax). عند أول تشغيل في 18/10 اتفقت مع قيمة Open-Meteo نفسها بانحياز −0.17 ومتوسط فرق مطلق 0.26 مم/يوم.
2. **تنبيهات الري:** تمتد الموازنة على أيام التوقع، فيظهر أحد ثلاثة تنبيهات: «ري الآن»، أو «ري متوقع يوم كذا» مع الرية المقترحة وكميتها، أو «لا حاجة حتى تاريخ كذا». يرافقها شريط بالأيام السبعة يعرض ET₀ والمطر واحتماله والعجز والعتبة والري، ويظهر آخر تنبيه أيضاً في لوحة التحكم.
3. **مطر التوقع:** يُحتسب فقط إذا بلغ احتماله العتبة (الافتراضي 60%)، وتُعلَّم الأيام التي لم يُحتسب مطرها.
4. **حد الرية حسب النظام:** القيم الافتراضية للحد الصافي: سطحي 80 مم، رذاذ 45 مم، تنقيط 20 مم. وكلها قابلة للتعديل، والعجز الزائد يُغطّى بريات متتالية.
5. **خريطة ET₀:** قيمة الدائرة تُختار بين يومي، أو متوسط الأسبوع الماضي، أو متوسط الأسبوع القادم. ومجموع الأسبوع ومصدره يظهران عند تمرير المؤشر.

## التشغيل لأول مرة على GitHub
1. **Settings → Pages:** اختر Deploy from branch، ثم الفرع `main` والمجلد `/ (root)`. يظهر بعدها رابط المنصة.
2. **Actions → NASA POWER sync → Run workflow:** اترك الحقول فارغة لتنزيل آخر 20 يوماً.
3. **ملء الأرشيف التاريخي:** شغّل الـ workflow يدوياً سنة بسنة، مثلاً `start=20250101` و`end=20251231`.
